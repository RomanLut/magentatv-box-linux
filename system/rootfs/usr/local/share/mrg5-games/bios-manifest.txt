# BIOS / firmware files the installed RetroArch cores look for.
#
# Format:  <filename>|<md5 or ->|<need>|<cores>|<what it is>|<hash source>
#
#   need        optional     - the core runs without it (built-in fallback)
#               feature      - needed only for the named feature (Mega CD, PCE CD, FDS)
#               recommended  - the core's own fallback is noticeably worse
#   hash source info         - hash printed by the core's own .info file on this box
#                              (/usr/share/libretro/info/, package libretro-core-info)
#               docs         - hash from the libretro documentation for that core
#               -            - no hash documented anywhere; any dump is accepted
#
# The files themselves are copyrighted by their manufacturers. They are NOT part of
# this project: dump them from your own hardware or obtain them lawfully. This file
# only records what the cores look for, so `bios-check` can tell you what is in
# place and whether the file you put there is the dump the core expects.
#
# Nintendo 64 is deliberately absent: mupen64plus_next_libretro.info has no firmware
# section, so ordinary N64 cartridge games need no BIOS at all. The 64DD disk add-on
# would want bios/Mupen64plus/IPL.n64 (md5 8d3d9f294b6e174bc7b1d2fd1c727530) in a
# subdirectory; no 64DD support is installed here.
